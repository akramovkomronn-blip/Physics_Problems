### String Harmonics: Wave Speed Calculation

To find the wave speed, we use the relationship between string length, wavelength, and frequency for the fundamental harmonic.

#### 1. Determine Wavelength ($\lambda$)

For a string fixed at both ends, the fundamental frequency (first harmonic) occurs when the length of the string ($L$) is equal to half a wavelength:

$$L = \frac{\lambda}{2} \implies \lambda = 2L$$

**Given:**

* $L = 64\text{ cm} = 0.64\text{ m}$

**Calculation:**

$$\lambda = 2 \times 0.64\text{ m}$$

$$\lambda = 1.28\text{ m}$$



---

#### 2. Calculate Wave Speed ($v$)

The speed of the wave is the product of frequency ($f$) and wavelength ($\lambda$):
$$v = f \lambda$$

**Given:**
* $f = 330\text{ Hz}$
  
* $\lambda = 1.28\text{ m}$

**Calculation:**

$$v = 330 \times 1.28$$

**$v = 422.4\text{ m/s}$**

---

#### Summary
* **String Length:** $0.64\text{ m}$
* **Wavelength:** $1.28\text{ m}$
* **Wave Speed:** **$422.4\text{ m/s}$**
